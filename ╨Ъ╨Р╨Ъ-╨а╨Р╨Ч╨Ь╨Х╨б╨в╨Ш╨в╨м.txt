Карманный финплан — как запустить для подписчиков

Итог: подписчики открывают ссылку t.me/ваш_бот/app в Telegram (iPhone, Android, компьютер).
Данные каждого хранятся в его собственном облаке Telegram — вы их не видите и не храните.
Та же ссылка на сайт работает и в обычном браузере (тогда данные хранятся на телефоне).

ШАГ 1. Разместить сайт (нужен адрес https), 10 минут
GitHub Pages (бесплатно):
1. Зарегистрируйтесь на github.com и создайте репозиторий (New repository), например finplan, тип Public.
2. Add file → Upload files → перетащите все файлы из этой папки (не саму папку) → Commit changes.
3. Settings → Pages → Source: Deploy from a branch, Branch: main, папка / (root) → Save.
4. Через 1–2 минуты сайт будет по адресу https://ваш-логин.github.io/finplan/
   Откройте его на телефоне БЕЗ VPN и проверьте, что открывается.
(Запасной вариант — app.netlify.com/drop: перетащить папку, зарегистрироваться, получить адрес.)

ШАГ 2. Создать мини-приложение в Telegram, 5 минут
1. Откройте в Telegram @BotFather → /newbot → название «Карманный финплан» → имя бота, например finplan_imya_bot.
2. Там же отправьте /newapp → выберите этого бота → название и короткое описание →
   картинку отправьте файл telegram-cover-640x360.png из этой папки → GIF пропустите (/empty) →
   адрес: ваш адрес из шага 1 (https://ваш-логин.github.io/finplan/) → короткое имя: app.
3. BotFather пришлёт ссылку вида https://t.me/finplan_imya_bot/app — это и есть ссылка для подписчиков.
4. (Необязательно) /setmenubutton → выберите бота → вставьте тот же адрес → текст кнопки «Открыть финплан».
   Тогда в чате с ботом будет кнопка открытия.

ШАГ 3. Проверить
- Откройте ссылку t.me/…/app на своём телефоне, добавьте пару трат.
- Откройте её же в Telegram на компьютере — траты должны быть там же.

Важно
- Адрес сайта из шага 1 выберите один раз и не меняйте.
- Обновить приложение: загрузите новый index.html в тот же репозиторий (Add file → Upload files). Данные людей сохранятся.
- Файл index.html нельзя открыть на телефоне просто как файл — только по ссылке.
